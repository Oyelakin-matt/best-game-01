NEON VOID — a neon space shooter built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC. Fly the last ship of the Vanguard against endless waves of the Void: drifters, weavers, spitters and asteroids, with a Void Leviathan boss every 5th wave. Grab spread, rapid-fire, shield and extra-life power-ups, chain kills for a combo multiplier, and chase the best score.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. WASD / arrows to fly, mouse to aim, click or Space to fire, P to pause, M to mute all audio. On touch devices the left thumb steers a virtual joystick and the right thumb aims and fires. A WebAudio-synthesised bass-and-arpeggio loop starts on the first tap or keypress. No build step, no network — plain static files under game/.
